# Loan-Default-Risk-Analysis

1. Project Title
Loan Default Risk Analysis & Scoring Dashboard


2. Short Description / Purpose
A data analytics project designed to analyze loan default patterns, identify key risk drivers, and segment loan applications using a rule-based risk scoring framework.
The project uses SQL for data preparation and analysis and Power BI for interactive visualization and risk monitoring.


3. Tech Stack
- PostgreSQL
- SQL
- Power BI
- DAX


4. Data Source
The project uses a publicly available loan dataset containing information such as:
- Loan amount
- Loan grade
- Annual income
- Employment length
- Loan purpose
- Borrower state
- Loan status
The data was cleaned, transformed, and analyzed using PostgreSQL before being connected to Power BI.


5. Features & Highlights
Business Problem:
Financial institutions need to identify loan segments with higher default rates and prioritize applications that may require additional credit review.

Key Questions:
- What is the overall loan default rate?
- Which loan grades have higher default rates?
- Which loan purposes show higher default rates?
- How does default risk vary by income level?
- How does employment experience relate to default risk?
- How does default rate vary by loan amount?
- Which states show higher default-rate concentrations?
- Which applications should be prioritized for manual review?

Key Features:

- Portfolio-level KPI analysis
- Default rate analysis by loan grade
- Income and employment risk analysis
- Loan-purpose risk analysis
- Geographic risk analysis
- Loan amount risk analysis
- Rule-based weighted risk scoring
- Risk tier classification
- High-risk application identification
- Manual review prioritization
